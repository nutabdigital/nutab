## Overview

**NuTab Digital** provides tailored software solutions for businesses and individuals. This website showcases our services, team, and contact information.

### Live Demo

Check out the live website: [nutab.ca](https://nutab.ca)

---

## Features

- Responsive and modern design.
- Smooth navigation with animations.
- Animated 3D background that morphs between brand-inspired shapes as you scroll (Three.js + GSAP).
- Interactive hero section with calls-to-action.
- About, Services, Our Team, and Contact sections.
- Contact form for inquiries.
- Dark and light mode toggle.

---

## Technologies Used

- **Framework**: [Next.js 16 (App Router)](https://nextjs.org/)
- **Language**: TypeScript + React 19
- **Styling**: Tailwind CSS (via PostCSS)
- **3D & Graphics**: Three.js (dynamically imported)
- **Animations**: Framer Motion, GSAP
- **Icons**: lucide-react, react-icons
- **Deployment**: Static export to [GitHub Pages](https://pages.github.com/)

## Getting Started

### Prerequisites

- Node.js 20.9+ (LTS recommended)
- npm or yarn

---

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/nutabdigital/nutab.git
   cd nutab
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Open http://localhost:3000 to view the website locally.

---

## Available Scripts

- `npm run dev`: Starts the Next.js dev server (webpack) and opens the app.
- `npm run build`: Builds the production bundle and exports the static site to `out/`.
- `npm run start`: Starts the production server (not used for static hosting).
- `npm run lint`: Runs ESLint checks.

---

### Build for Production

To create a production build:

```bash
npm run build
```

Because `next.config.mjs` sets `output: 'export'`, this also writes the static site to `out/` — no separate export step is needed.

## Project Structure

/app - Next.js App Router source
layout.tsx - Root layout, metadata, fonts, SEO
page.tsx - Home page
sitemap.ts - Generated sitemap (built to `out/sitemap.xml`)
/styles - Global styles (Tailwind + CSS)
/components - Reusable UI components (with co-located CSS)
/components/Model - 3D morphing background (Three.js renderer + shape definitions)
/context - Context providers (theme/model/section state)
/services - Services index + detail routes (ai-automation, app-development,
brand-design, ecommerce, it-consulting, photo-media, seo-marketing, web-design)
/portfolio - Portfolio page route
/privacy, /terms, /cookies, /accessibility - Legal & policy pages
/public - Static assets (icons, photos, robots.txt, _headers)
/data - Data helpers (e.g., image sizes)
/out - Static export output (generated by `npm run build`)
next.config.mjs - Next.js config (static export + perf)
tailwind.config.ts - Tailwind configuration
postcss.config.mjs - PostCSS plugins
tsconfig.json - TypeScript configuration

## Deployment

This project is configured for static export and hosting on GitHub Pages.

1. Build the static site:
   ```bash
   npm run build
   ```
   The static site is generated in `out/`.
2. Deployment is automated: the GitHub Actions workflow in `.github/workflows/deploy.yml` builds and publishes `out/` to GitHub Pages on every push to `main`.
3. A `CNAME` file is included for the custom domain `nutab.ca`.
4. Images are configured as unoptimized for static export (`next.config.mjs`).
5. `public/_headers` is copied into `out/` for hosts that support it (e.g., Netlify, Cloudflare Pages). GitHub Pages ignores it, so the security/cache headers in it are not applied on the live site.

## SEO & Analytics

- Metadata: Configured in `app/layout.tsx` using Next.js `Metadata`.
- Open Graph & Twitter: Titles, descriptions, images set for social sharing.
- Structured Data: JSON-LD for Organization/LocalBusiness injected in layout.
- Sitemap & Robots: sitemap generated from `app/sitemap.ts` (built to `out/sitemap.xml`); `public/robots.txt` included.
- Google Analytics: `gtag.js` loaded with delayed page_view and IP anonymization.
- Dark/Light Mode: `data-theme` persisted via `localStorage`; toggle component provided.
